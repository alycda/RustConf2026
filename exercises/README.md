## Ground rules

- **Pick your day first** (menu: `../days/README.md`). Any day works in any
  exercise — the boundary steps are identical.
- AI assistance is welcome: delegate the boring parts, write the boundary 
  yourself first.
- Never paste your real AoC puzzle input into these files' tests — use the
  small examples from the puzzle statement.

Prework option: Ex 1 can be completed before the workshop. If you arrive
with it done, you'll have the option of starting with the bonus for Ex1 or 
start Ex 2 early (or help a neighbor) — all are valid.
